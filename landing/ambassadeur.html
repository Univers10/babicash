Comment ça marche ?

Quatre étapes simples pour commencer à gagner.

1

Créez votre compte

Inscrivez-vous en tant qu'ambassadeur. Choisissez un code de parrainage personnalisé (4 à 20 caractères) et renseignez votre numéro Mobile Money pour les versements.

2

Partagez votre code

Communiquez votre code à des commerçants, gérants de boutiques et entrepreneurs. Chaque filleul inscrit avec votre code est définitivement rattaché à votre compte.

3

Ils s'abonnent

Vos filleuls adoptent BabiCash et paient un abonnement adapté à leur activité. Vous générez des commissions dès qu'un paiement est confirmé.

4

Encaissez

Vos commissions sont regroupées chaque semaine dans un lot de versement, puis transférées sur votre Mobile Money. Suivez tout depuis votre espace ambassadeur.

Règles du programme

Quelques règles pour un programme juste et durable.

Code personnalisé

Votre code est unique sur toute la plateforme. Il est composé de 4 à 20 caractères (lettres et chiffres), sans espace, et stocké en majuscules.

Pas d'auto-parrainage

Vous ne pouvez pas utiliser votre propre code sur votre propre compte commerçant. Le rattachement est définitif dès la première inscription.

Commission sur abonnement payant

Les commissions ne sont générées que sur les paiements d'abonnement confirmés. Le plan FREE ne génère aucune commission.

Fenêtre de 12 mois

Chaque filleul génère des commissions pendant 12 mois à compter de son premier paiement. Après cette période, plus aucune commission n'est due.

Versement hebdomadaire

Les commissions validées sont regroupées chaque semaine. Un versement vous est effectué sur le numéro Mobile Money renseigné dans votre profil.

Anti-fraude

Toute tentative d'abus (faux comptes, informations erronées) entraîne la désactivation du code et l'annulation des commissions non versées.

Questions fréquentes

Qui peut devenir ambassadeur ?

Toute personne majeure disposant d'un numéro de téléphone valide et d'un compte Mobile Money. Vous n'avez pas besoin d'être commerçant pour parrainer.

Comment suivre mes commissions ?

Connectez-vous à l'espace ambassadeur pour consulter votre solde, vos filleuls, l'historique de vos commissions et l'état de vos versements.

Quand suis-je payé ?

Les commissions validées sont regroupées une fois par semaine. Le versement est effectué par Mobile Money dès validation administrative.

Le filleul peut-il changer de parrain ?

Non. Le rattachement est définitif dès l'inscription du filleul avec votre code.

Que se passe-t-il si mon code est désactivé ?

Si votre code est désactivé pour fraude, les filleuls déjà rattachés continuent de générer des commissions, mais vous ne pouvez plus attirer de nouveaux filleuls.
